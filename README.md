A one-line excuse, spoken by the GPS itself: the map promised a bridge, the river disagreed, and the scenic detour past the lake was payback for being muted every trip. Run the program and it writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Running it checks the line first (non-empty, one line, 1–200 characters, no control characters, valid UTF-8), writes it to
`/output/entry.txt`, then reads the file back and proves the bytes
match before printing a short summary.
